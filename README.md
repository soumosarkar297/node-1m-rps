# Node Project for 1M rps

This repository is used as an example for Handling 1 Million Requests per Second.

## Setup

1. Have Node.js and Docker installed.

2. Run docker and docker compose file:

   ```bash
    docker compose up -d
   ```

3. Run the node server:
   - express server: `node express.js`
   - fastify server: `node fastify.js`
   - cpeak server: `node cpeak.js`
